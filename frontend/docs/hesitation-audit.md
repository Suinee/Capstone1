# 감지 항목 점검 및 왕복 누적 수정

기준 커밋: `16e14f2`. 엔진의 8개 규칙과 화면의 행동 수집 경로를 점검했다.

## 확인된 결함과 수정

1. 왕복 규칙은 30초 측정시간 안의 A→B→A→B→A를 2점으로 판단했지만,
   다음 화면에서 전체 점수가 0으로 초기화되어 왕복만으로 도움 기준 3점에 도달하기 어려웠다.
   **왕복 기여 점수만 화면 이동 후 유지**하도록 수정했다. 화면 내부 클릭/입력 등의 점수는
   종전처럼 새 화면에서 초기화한다. 개발 패널에 두 점수의 내역을 표시한다.
2. 250ms 간격의 정기 평가만 기다리면 짧은 화면 방문이 누락될 수 있었다.
   화면 진입 또는 로딩 완료로 측정이 재개될 때 즉시 평가한다.
3. 라디오·체크박스의 라벨 텍스트에 hover하면 입력 요소의 식별자를 찾지 못했다.
   연결된 label.control로 수집 대상을 찾는다. 라벨 클릭과 전달된 입력 요소 클릭을
   두 번 세지 않도록, 실제 전달된 입력 요소의 클릭만 기록한다.
4. 첫 스크롤을 기준점으로만 사용하여 첫 왕복의 첫 이동이 빠졌다.
   수집 시작 시 페이지/기존 스크롤 영역의 위치를 기준점으로 저장한다.
5. checkbox/radio의 input 이벤트에도 2초 뒤 input_pause 타이머가 걸렸다.
   실제 텍스트 입력 항목으로 제한하여 선택을 입력 중단으로 오인하지 않게 했다.
6. 완료 상태에서도 내부 활성 시간이 증가할 수 있었다. 완료 후 대기 시간은 활성 시간에서 제외한다.
7. `test:hesitation` 명령이 존재하지 않는 테스트 파일을 참조했다.
   엔진·공공서비스 감지·도움 테스트를 실행하도록 복구했다.

왕복 점수는 같은 공공서비스 과제에서만 유지하며 서비스 변경·완료 후 새 과제·새 시도에서 초기화한다.
키오스크는 같은 엔진 세션 내 화면 이동에 같은 처리를 적용한다.
5초 판단 묶음의 최대 점수 정책은 유지한다. 같은 묶음에서 클릭 2점과 왕복 2점이
함께 발생해도 4점으로 합산하지 않으며 왕복 기여분만 다음 화면에 보존한다.

## 오류가 아니라 현재 설정상 점수가 오르지 않는 조건

| 항목 | 현재 가산 조건 | 단독으로 가산하지 않는 동작 |
| --- | --- | --- |
| 시간 지연 | 화면 기준시간 초과 + 최근 20초 보조 행동 근거 | 아무 조작 없이 기다리기 |
| 항목 체류 | 미사용 hover 시간 8초 이상 | 8초 미만 hover, 터치 기기의 hover 없음 |
| 과도한 hover | 같은 항목에 최근 20초 내 5회 진입 + 합계 3초 체류 | 짧은 진입/이탈 반복만 수행 |
| 복합 탐색 | 포인터 멈춤·방향 전환·입력 중단·스크롤 왕복 중 2종류 이상 | 마우스 이동 또는 스크롤 왕복 하나만 수행 |
| 반복 클릭 | 같은 항목을 2초 내 3회 클릭 | 서로 다른 선택지를 한 번씩 클릭 |
| 입력 반복 수정 | 2초 입력 중단 이후 같은 항목에서 삭제→재입력 2회 | 입력만 하기, 삭제만 하기, 멈춤 없이 수정하기 |
| 반복 오류 | 같은 항목·같은 오류를 서로 다른 시도에서 2회 발생 | 비활성 버튼 클릭, 서버 통신 실패 |
| 이전 단계 왕복 | 측정시간 30초 안에 A→B→A→B→A | A→B→A 한 번 왕복, 시간 범위를 벗어난 이동 |

모든 규칙은 사용한 근거의 중복 가산을 방지한다. 같은 규칙은 5초 간격을 두고 다시 가산하며,
같은 5초 판단 묶음에는 가장 큰 후보 점수만 반영한다. 약한 신호 1점, 강한 신호 2점,
도움 기준은 3·6·9점이다. **판단 신호가 발생했다고 항상 누적점수가 증가하는 것은 아니다.**
개발 패널의 최근 신호와 judgment 로그의 addedScore를 함께 확인한다.

공공서비스 반복 오류는 주민등록 신청의 필수 항목 검사와 전입신고 이전주소 조회 검사에 연결되어 있다.
가족관계/납세증명은 현재 기본값으로 신청 가능하고, 전입신고의 나머지 필수 미완료 항목은
다음 버튼을 비활성화하므로 검증 오류 이벤트를 발생시키지 않는다.
키오스크에는 텍스트 입력이 없어 inputRevision/repeatedError를 활성화하지 않는다.

## 검증

- 8개 규칙별 엔진 가산, 빠른 왕복, 누적 유지, 서비스 변경 초기화, 최대 점수/중복 정책 테스트
- 브라우저에서 전입신고 실제 이전/다음 버튼 왕복으로 2→4점 누적 및 자동 도움 확인
- 라벨 hover의 체류 점수, 클릭 중복 방지, 체크박스의 잘못된 입력 중단 없음 확인
- 첫 스크롤 왕복 지표 확인

```sh
npm run test:hesitation
npm run test:public-service
npm run build
```

감지 규칙 버전: 공통 `target-help-1.2`, 공공서비스 `public-help-1.1`.

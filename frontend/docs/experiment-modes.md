# 기본 / 적응형 실험 모드

## 시작 방법

1. 홈에서 키오스크 또는 공공서비스의 `체험 시작하기`를 누른다.
2. 설정 화면에서 기본 모드 또는 적응형 모드를 명시적으로 선택한다.
3. `선택한 모드로 시작하기`를 누른다.

홈 상단의 `실험 설정` 또는 `/experiment`에서도 서비스와 조건을 선택할 수 있다.
서비스 주소에 직접 접근한 경우에도 해당 서비스의 설정이 없으면 먼저 설정 화면을 표시한다.
설정 화면에서는 행동 수집을 시작하지 않는다.

| 조건 | 기본 모드 (`baseline`) | 적응형 모드 (`adaptive`) |
| --- | --- | --- |
| 행동 수집·8개 규칙·점수 계산 | 동일 | 동일 |
| 자동 도움·자동 강조 | 꺼짐 | 기존 3/6/9점 기준으로 표시 |
| 사용자가 요청하는 수동 도움 | 사용 가능 | 사용 가능 |
| 로그 저장·재전송 | 동일 | 동일 |

이번 비교는 **수동 도움을 공통으로 제공할 때 자동 도움을 추가하는 효과**를 대상으로 한다.
기본 모드에서도 점수와 감지 수준은 올라갈 수 있지만 자동 도움은 열리지 않는다.
도움 제공 여부는 감지 수준이 아니라 `help` 로그의 `status`, `reason`, `level`로 판단한다.

## 실행 조건과 기록

- 선택한 조건은 같은 탭의 sessionStorage에 저장된다. 페이지 이동·새로고침 후에도 유지된다.
- 진행 중 조건을 변경하는 스위치는 없다. 홈 → 실험 설정에서 다시 시작하면 새 `runId`를 발급한다.
- 조건 또는 서비스를 바꾸어 시작하면 감지 Provider를 새로 생성해 점수·도움 상태를 초기화한다.
- 새로고침 때 엔진 `sessionId`는 새로 발급되지만 실험 `runId`는 유지된다.
  이전 과제 화면의 입력값·점수까지 복원하는 기능은 아니다.
- 저장소가 차단되거나 저장에 실패하면 안내 메시지를 표시하고 시작하지 않는다.
- 오래되거나 잘못된 저장 설정은 사용하지 않고 다시 선택하게 한다.
- 개발용 감지 패널에서 모드, 자동/수동 도움 정책, 실험 ID를 확인할 수 있다.

모든 신규 실험 로그에는 아래 `experiment` 객체가 포함된다.

```json
{
  "runId": "실험 시작 시 발급한 UUID",
  "mode": "baseline",
  "service": "kiosk",
  "automaticHelp": false,
  "manualHelp": true,
  "policyVersion": "automatic-help-ab-1.0",
  "startedAt": 1793000000000
}
```

`service`는 `kiosk` 또는 `public-service`다. 설정은 엔진 생성 시 고정되며,
새 실험 시작 후 이전 로그를 재전송해도 그 로그의 조건은 바뀌지 않는다.
기존 백엔드의 JSON 원문 보존 방식으로 저장하므로 DB 마이그레이션은 필요하지 않다.
`experiment`가 없는 과거 로그를 기본 모드로 간주하면 안 된다.

공공서비스 네 민원은 선택한 공공서비스 실행 조건을 공유한다. 개별 서비스는
기존 화면 ID·과제 context로 구분한다. `runId`는 참가자 ID나 과제 ID를 의미하지 않는다.

## 범위와 검증

조건 선택·유지·표시 정책·로그 태깅에 과제 완료 결과 집계와 CSV 내보내기를 연결했다.
사용 방법과 지표 정의는 [과제 결과 문서](task-results.md)를 따른다. 무작위/교차 배정,
참가자 관리, 통계적 검정은 후속 작업이다.
AI 도움, 금융서비스, 도움창 겹침 방지, 직원 호출은 변경하지 않았다.

```sh
npm run test:experiment
npm run test:hesitation
npm run test:public-service
npm run build
```

백엔드에서는 `HesitationLogApiTests`가 두 조건의 저장·조회·중복 재전송을 검증한다.
프론트 테스트는 실제 점수 엔진과 도움 구독 로직을 연결해 두 조건의 점수 동일성,
기본 모드 자동 도움 억제, 적응형 자동 도움, 수동 도움, 화면 전환, 설정 보존을 검증한다.

수동 확인: 공공서비스 주민등록 신청에서 주소를 선택하지 않고 신청하기를 두 번 누른다.
5초 이상 지난 뒤 반복해 3점 이상이 되었을 때, 기본 모드는 자동 안내가 없고
적응형 모드는 안내가 나타나는지 비교한다. 두 모드 모두 `화면 도움 받기`는 사용할 수 있어야 한다.
실제 참가자 실험에서는 개발 패널이 없는 제품 빌드를 사용한다.
